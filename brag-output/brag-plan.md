# Clementine — A little less drag

## Inspection rubric
1. Clementine is a native Swift menu-bar utility for local file conversion, editing, and file actions.
2. Its strongest claim is the short journey from a file drag to a useful result, without uploading the file.
3. The visual hook is the orange radial wheel blooming beside a dragged file.
4. Use the actual `Resources/Wheel.png`, actual editor screenshot, and original app icon. Surrounding cursor/file animation is a staged demonstration, not a screen recording.
5. The shortest satisfying film shows a JPG dragged, Shift pressed, BMP selected, then a new BMP file. Finish with the native editor and product name.
6. Polished / app-store; cream, citrus orange, brown ink, translucent surfaces, restrained spring motion.
7. Original instrumental bed and three soft original interaction accents; no voiceover. The website background derivative is silent.
8. Share caption: “Clementine. A little less drag. Convert, edit, and move files right on your Mac.”
9. Entry → action → result: drag Coast.jpg → tap Shift → drop on BMP → Coast.bmp beside the original. Conversion selection in the screenshot is BMP, so the demonstration names BMP rather than inventing a PNG selection.
