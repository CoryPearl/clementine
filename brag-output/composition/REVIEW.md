A general feature montage and an abstract citrus animation were rejected because the interaction explains the product more clearly.

Inspected: full-resolution wheel frame, scene beat sheet, phone sheet, and scene seams. The actual editor is the weakest phone-size shot: its small controls illustrate the product rather than serve as instructions. A dedicated close-up would improve a longer cut.

Retained warnings: the three small transition wrappers remain inline, allowing one editable root wipe track. The short wheel hold gives viewers time to read the format choices; the cursor then moves to the selection. The source composition starts on an entrance, but delivery frame zero is replaced with the settled 5.8-second poster as required by Brag.

The film is a staged demonstration using actual interface assets, not a live screen recording. Native Liquid Glass's dynamic backdrop cannot be captured by the app's offscreen snapshot renderer, so these assets show its static tint approximation.
